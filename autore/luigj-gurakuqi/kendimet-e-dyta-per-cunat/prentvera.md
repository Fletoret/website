Bora ka shume kohe qe u-trét nga arat é nga fushat; vétem mbi majét é malévét ka mbétun aty ketù nga nji çike mbulése é bardhe. Njenat é perronjévet é te lumenjvet u-liruan nga akulli dhé rrédhin mé nga dale é ndritin nga rrézét é diéllit. Vériu mâ s'fryn i forte, gjemimi i drunjevét qe tundéshin nga éra é rrébte, nuke ndegjonét mâ, po vétem nja ére é léhte é é bute lemon é perkedhéle flétet é lulét. Niégulla é dendune é é érrte s'i mbulòn mâ malét é fushat; déti bâhét i paqie é nuke ka vale é tallazé te rrebta, po faqéja é 'tij dridhét é shkelqèn é xixillòn si nje pasqyre é madhé. Malét, kodrat, pyjét, fushat, arat livadhét marrin nje ngjyre te blére nga bari, nga flétet, nga bimet qe çélin é lulezojen. Dallendyshét é zoqt é tjére qe na kishin lâne vétem ne dimen, zâan é kethéhén pak nga pak, é fushat é pyjét ushtojen permalleshem nga kânga é 'tyné é ambele.

Érdhi prentvéra! Dimeni shkoi! Gjithesia çélét, sbukuronét, qéshét, âsht ne gezim! Diélli ngrohe é ndrite, qiélli âsht i rrimte é i kthjéllte, ujenat é kronit é te lumit shkelqéjen nga rrézét é diéllit é murmurojen duké rrédhun ndeper fléte é ndeper lulé. Mengjési âsht i âmbel é nje vése é holle pushon mbi barin é njome é mbi lulét, nje ére é kândeshmé perhapét ndeper ajer, zoqt kendojen drizavér, blélet é fluturat shkojen duké qendruar lulé mbe lulé. Édhé krimbat, hardhjét é gjarpinjt dalin jashte é ngrohén ne diéll.

Mbrâmja prape âsht é bukure! Pas pérendimit te diéllit, kur nise é érrét nata, dél hâneza é argjendete bashke mé mija hyjsh é leshòn driten è 'saj t'âmbele è te bardhe mbi boten qe pushon, mbi zoqt qe flêjen nde foléet é 'tyné, mbi kafshet qe shtrihén nde shtrofkullat é véta.

Nga nje hére bié nje shi i bute é i léhte qe gezòn é kenaqe gjithe vendin. Te mbjéllunat bijen, ushqéhén, rritén; fusha mérr jéte é fuqie te rée; bimet, bari, lulét fluturojen aravét é fushavét; déget mbushén mé fléte, mé bubuqé, mé lulé; trendafillét hapén ndeper kopshtinjé. Kulpeni ngjitét ndeper drunje, é mbulòn è bléròn murét é lédhét.

Te gjitha krijésat é Zotit ne kohe te prentvéres sgjohén, tundén, gezohén. Édhè péshqit n'uje levizin é dalin hére é hére te shohin diéllin.

Malét, kodrat, fushat mbulohén mé bagetie; shqérrat é kédhat é végjele kercéjen é blégerojen ndukin barin é pijen qumesht; bariu rri nen hijén é lisit è bié fyéllit permalleshem.

Bujku zen qét é leròn arat, kopshtari mbiéll barishtét, punetori sbukuròn lulishtat.

Stina mâ é mira é motit âsht prentvéra; syni nuke te shéh tjater véç bukurie; véshi nuke te ndegjòn tjater véç kânge; Zêmêra te kenaqét é te gezohét!
